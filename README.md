# minIFF: a simple proof of concept of a drone IFF

minIFF is a proof of concept aiming at showing that designing an efficient secure IFF for drones can easily be done at a very cheap price.

This is only a proof of concept for now and the actual implementation is a bit flimsy, especially when it comes to user interface (it is essentially non-existing for now).

However, the overall cryptographic protocol should not vastly change and its design [whitepaper is already available](./WHITEPAPER.md).
